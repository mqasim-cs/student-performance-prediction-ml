# Predictive Modeling of Student Academic Performance

A machine learning and deep learning system designed to predict student academic performance using demographic, behavioral, and lifestyle factors.

## Objective
Predict student grades using factors such as:

- Study time
- Sleep schedules
- Attendance
- Stress levels
- Demographic variables

## Statistical Analysis
- Chi-Square Test of Independence
- Independent T-Test
- Pearson Correlation

## Machine Learning Models
- Logistic Regression
- Support Vector Machine (RBF)
- Random Forest
- XGBoost
- Neural Network (TensorFlow/Keras)

## Deep Learning Architecture

Input Layer (14 Features)

Hidden Layer 1: 128 ReLU + Dropout(30%)

Hidden Layer 2: 64 ReLU

Hidden Layer 3: 32 ReLU

Hidden Layer 4: 32 ReLU

Output Layer: 6-class Softmax

## Techniques
- Stratified Train-Test Split
- Feature Engineering
- StandardScaler
- Dual-Pipeline preprocessing
